# UI 교체와 화이트·다크 검증

## 반영한 변화

- 문제집을 행 중심으로 개편하고 실제 전체 건수, 난이도 필터, 페이지 이동을 연결했다.
- 페이지·난이도를 URL에 기록해 상세 화면 복귀와 새로고침에서도 유지한다. 이전 요청의 늦은 응답은 새 결과를 덮어쓰지 않는다.
- 상세는 질문 읽기와 생각 정리 순서를 분리했다. 답변 제출·평가 API는 아직 없어 입력·제출을 가짜로 제공하지 않는다.
- 로그인·회원가입·관리자 화면까지 같은 스타일과 테마를 적용했다. 미구현 추천·지식 지도와 내부 인증 구현을 홍보하던 문구를 제거했다.
- 화이트·다크·시스템 선택과 저장, 시스템 테마 변경 추적, 저장소 차단 시에도 전환을 지원한다.
- 최초 스타일 로드 전에 테마를 복원한다. 키보드 포커스, 본문 건너뛰기, 모션 감소 설정을 지원한다.

## 명암 대비

CSS에 정의된 실제 색상 조합 40개 테스트를 통과했다. 이 수치는 전체 WCAG 준수 인증을 의미하지 않는다.

| 조합 | 화이트 | 다크 | 기준 |
|---|---:|---:|---:|
| 본문 / 페이지 | 14.58:1 | 15.83:1 | 7:1 |
| 보조 문구 / 페이지 | 8.14:1 | 10.61:1 | 7:1 |
| 보조 문구 / 보조 배경 | 7.40:1 | 8.14:1 | 7:1 |
| 주 버튼 글자 / 버튼 | 8.31:1 | 10.58:1 | 4.5:1 |
| 입력 테두리 / 입력면 | 3.86:1 | 5.18:1 | 3:1 |

상태 알림 글자 4.5:1 이상, 포커스와 조작 경계 3:1 이상도 검사한다. 상태는 색상과 함께 문구로 제공한다.

## TDD 증거

1. 테마 선택이 없어서 새 행동 테스트 5개 실패 → 선택·저장·시스템 추적 구현 → 통과.
2. 기존 보조 문구 대비가 부족하고 다크 색상이 없어 대비 테스트 실패 → 색상 구성 및 보정 → 통과.
3. 페이지·필터 요청과 전체 건수 테스트 5개 실패 → API와 UI 연결 → 통과.
4. 독립 코드 검토에서 목록 복귀 시 위치 소실 발견 → URL 저장·복원 테스트 2개 실패 확인 → 구현 후 통과. 재검토에서 지적 해결 확인.

검증 중 테스트 환경의 저장소 제공 방식과 CSS raw import 처리 차이를 수정했다. 대비 테스트는 앱 코드 밖 `front/tests/contrast.test.ts`에서 실제 SCSS 파일을 읽는다.

## 브라우저 확인

- 실제 임시 DB에 로그인 → 문제 조회 → 난이도 선택 → 상세 → 목록 복귀 → 새로고침 후 조건 유지.
- 화이트/다크 로그인, 다크 선택 후 새로고침 유지.
- 문제집·상세·관리자 폼의 모바일 배치. 390px 화면 확인.
- 320px 관리자 화면에서 스크롤바를 제외한 clientWidth와 scrollWidth가 305px로 같아 가로 넘침 없음.
- 필터 빈 결과, 회원가입 필수값 오류를 실제로 표시해 확인. 회원을 생성하지 않았다.
- 모바일에서 숨긴 본문 건너뛰기 링크가 부분 노출되는 문제와 최소 너비에 따른 가로 넘침을 보정했다.

## 경계와 실행 환경

기존 파일 기반 local DB는 이전 스키마와 예제 SQL의 충돌로 시작되지 않았다. 데이터 삭제나 초기화로 해결하지 않았다. UI 검증은 별도 메모리 DB로 실행했다.

```bash
./gradlew bootRun --args='--spring.profiles.active=local --spring.datasource.url=jdbc:h2:mem:crackcs-ui-review --spring.jpa.hibernate.ddl-auto=create-drop'
npm --prefix front run dev -- --host 127.0.0.1
```

현재 실행 중인 미리보기는 해당 임시 DB를 사용하므로 서버 종료 시 데이터가 사라진다. 기존 파일 DB 문제를 복구하는 작업은 포함하지 않았다. 조회 페이지 이동은 자동 테스트로 검증했고, 실제 seed는 1문제라 여러 페이지 데이터로 브라우저 검증을 수행하지 않았다. 실제 모바일 기기·모든 브라우저·스크린리더 사용자 테스트는 미실시다.

기존 사용자 수정 파일은 보존했다. 커밋·원격 배포는 수행하지 않았다.
