# 제한 파일럿 runbook

## 상태

- 상태: 실행안 준비
- 미실행: 실제 날짜, 참가자 모집, 운영 결과, P0/P1 결정
- 시작 승인자: 프로젝트 소유자
- 운영 담당: 관리자 1명 이상
- 기술 담당: 장애·로그 조사 담당 1명 이상

## 제안 범위

- 대상: 초대된 학습자 5~10명
- 기간: 연속 7일
- 콘텐츠: [초기 콘텐츠 기준](content-readiness.md)을 통과한 leaf Topic만
- provider: 실제 모델 Gate가 별도로 승인된 환경만. 현재 로컬 구현 검증은 OpenAI 제외
- 실제 `시작일`, `종료일`, `참가자 ID`, `환경`, `모델/평가기 버전`: 미정·미실행

## 시작 전 Gate

- backend/frontend 자동 검증 성공
- 치명적·높은 보안 결함 0건
- production-equivalent backup·restore 성공 증거
- 실제 모델 품질·비용·latency Gate 통과
- 대상 콘텐츠 전수 검수와 OQ-006 충족
- 관리자 실패 조회와 `requestId` 추적 가능

하나라도 미충족이면 참가자를 받지 않는다.

## 신고와 관리자 처리

```text
사용자 신고
  ↓ requestId + answerId + 증상 수집(비밀번호·세션 제외)
운영 담당 triage
  ↓
P0/P1 즉시 기술 담당 호출 ── 필요 시 파일럿 중단
P2 1영업일 내 관리자 검토
P3 다음 운영 회의에서 우선순위 결정
```

| 등급 | 예 | 최초 확인 SLA | 조치 |
|---|---|---:|---|
| P0 | 회원 간 데이터 노출, 비밀정보 노출, 데이터 손실 | 15분 | 즉시 중단, 접근 차단, 증거 보존 |
| P1 | 반복 오판정으로 상태 오염, 광범위 평가 불능 | 1시간 | 신규 제출 중단 검토, 원인 격리 |
| P2 | 단일 오판정, 콘텐츠 누락, 반복 추천 | 1영업일 | 관리자 판정·콘텐츠 보완 |
| P3 | 문구·사용성 개선 | 3영업일 | backlog 분류 |

## 수집 지표

| 지표 | 계산 | 관찰 목적 |
|---|---|---|
| 평가 실패율 | 실패 Evaluation / 전체 Evaluation | provider·worker 안정성 |
| 평가 완료 latency | 접수~완료 p50/p95 | 사용자 대기와 병목 |
| 콘텐츠 부족률 | 근거 부족 또는 풀 수 있는 문제 없음 / 학습 시도 | 공개 범위 준비도 |
| 반복 추천률 | 같은 사용자에게 연속 동일 문제 추천 / 전체 추천 | 추천 막힘 |
| blocked-user | 10분 이상 다음 행동 불가한 사용자/사례 수 | 치명적 흐름 단절 |
| 오판정 신고율 | 확인된 판정 신고 / 완료 Evaluation | 평가 품질 |

원문 답변은 일반 운영 로그에 복사하지 않는다. 상세 조사는 권한이 제한된 관리자 조회로 수행한다.

## 제안 중단 조건

- 보안 P0 1건 이상
- 복구 불가능한 데이터 손실 또는 Evidence 참조 손상 1건 이상
- 동일 원인의 P1 평가 장애가 30분 이상 지속
- 24시간 rolling 평가 실패율 5% 초과
- 평가 완료 local/production p95 목표 초과가 2시간 지속
- 확인된 오판정이 Knowledge State를 광범위하게 오염
- blocked-user가 2명 이상이며 우회 절차 없음

임계값은 파일럿 시작 승인 시 실제 환경 기준으로 다시 확정한다. 현재 값은 실행안이며 결과가 아니다.

## 일일 운영

1. 실패율·latency·근거 부족·반복 추천 dashboard/query 확인
2. P0/P1 미해결 건 확인
3. 전일 신고를 오판정·콘텐츠·UI·운영 문제로 분류
4. 잘못 공개한 콘텐츠는 retire 후 [rollback 절차](content-readiness.md) 적용
5. 변경된 모델·평가기·콘텐츠 버전을 일지에 기록
