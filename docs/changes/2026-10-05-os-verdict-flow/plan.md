## 책임과 관찰

```text
cmux 실제 답변 제출 → Answer·Evaluation 저장 → 공개 v2 Chunk 검색 → 실제 GPT
                                                        ↓
                          EvaluationEvidence + 개념별 판정 + KnowledgeApplication
                                                        ↓
                                 지식 지도·추천·한 단계 후속 질문
```

- Answer: 원문과 요청 멱등성
- Evaluation: 판정·개념별 점수·평가 당시 근거와 모델 사용 기록
- Knowledge State: 유효 개념 판정별 정확히 한 번 적용, 최신 가중 평균·횟수·신뢰도
- FollowUpGeneration: 기본 답변별 최대 한 후속, 후속 답변 뒤 추가 생성 제한
